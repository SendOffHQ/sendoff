Social

Instagram set

Rendered from ig.html in headless Chromium, so the slides use the app's own type, colour tokens and wordmark rather than an approximation of them. Long-press any image to save it.

Intro carousel

Six slides at 1080×1350. Post them in order as one carousel.

Stories

The same six at 1080×1920. Redrawn rather than rescaled: Instagram covers roughly the top and bottom 250px, so everything readable sits between them and the extra height went into larger type.

Profile triptych

The wordmark across three tiles. Post them 3, then 2, then 1: the grid fills right to left along the top row, so that order puts them left to right.

The tiles overlap by 40px, about four screen pixels at grid size. Too little to read as a repeat, enough that nothing lands in the gutter between tiles.

Rebuilding the set

  1. Edit brand/social/ig.html.
  2. node shoot.js && python3 cut.py in that directory.
  3. Commit the regenerated PNGs, or the images here stop matching their source.

The fonts are vendored locally on purpose. The first build linked Google Fonts, the renderer had no network, and every image came out in a system fallback before anyone noticed. shoot.js now exits non-zero if a face is missing. See README.md.
